Backtest controls: does the engine itself behave?

Before judging a setup, check that the engine neither invents edge nor misses real edge.

Definition

A negative control is a driftless random walk with random signals: the result must be about minus costs. A positive control plants a drift after each signal: the engine must see it. Both run in the tests and the table below.
